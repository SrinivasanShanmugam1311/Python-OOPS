
# Python Object-Oriented Programming (OOP) Using Python

# Module 01 – Python Object Model & Class Fundamentals

> **Course Level:** Intermediate → Advanced  
> **Module Duration:** 1 Day (1–2 Hours)  
> **Prerequisites:** Python Basics, Functions, Loops, Collections, Modules

---

# Module Overview

This module builds the foundation for the entire Object-Oriented Programming course. Instead of simply learning how to create classes and objects, you will understand **how Python internally treats objects**, how memory is managed, how variables reference objects, and how classes are designed in a Pythonic way.

This module focuses on understanding the **Python Object Model**, which is essential before learning inheritance, polymorphism, design patterns, or advanced software architecture.

---

# Learning Objectives

After completing this module, you will be able to:

- Explain Object-Oriented Programming concepts.
- Understand why everything in Python is an object.
- Create and initialize classes and objects.
- Differentiate between class variables and instance variables.
- Understand constructors and object initialization.
- Understand object identity and equality.
- Explain mutable and immutable objects.
- Understand namespaces and scope resolution.
- Inspect Python objects using introspection functions.
- Understand object lifecycle and garbage collection.
